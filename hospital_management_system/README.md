# CarePoint Hospital Management System (Frontend Demo)

## Features
- Login and logout flow
- Dashboard summary cards
- Patients, doctors, appointments and billing navigation
- Demo data tables
- Responsive layout for desktop and mobile

## Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` directly, or install the VS Code **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.

## Demo login
- Username: `admin`
- Password: `admin123`

## Notes
This is a frontend-only demonstration. Login state uses browser session storage and sample data is hardcoded. It is not secure authentication and is not suitable for real patient information. A production system requires a backend, database, role-based access, secure authentication, audit logs, and appropriate privacy/security safeguards.
